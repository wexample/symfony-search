# Extraire et moderniser la recherche dans symfony-search

Opened: 2026-09-15
Updated: 2026-09-15
Author: agent:main

## But

Une recherche **transverse** dans `wexample/symfony-search`, dont les entités Doctrine ne
sont qu'un cas parmi d'autres — les pages routées en sont un second.

## Décisions actées

1. **`SearchResult` est une entité sans ORM.** `#[PseudocodeExport]`, pas de `#[ORM\Entity]`.
   Elle hérite de la standardisation : export `entity.ts`, repository front généré, vues =
   collections d'entités. Le legacy faisait déjà ça ; le faux `#[ApiResource]` ApiPlatform
   qui l'entourait est retiré.
2. **La route suit la convention entité** : `api/search-result/list`, pas `/_system/`.
   Le `SearchResultRepository.ts` généré la consomme sans câblage.
3. **symfony-forms dépendra de symfony-search** et y wrappera la recherche dans un field.
4. **SQL seulement.** Pas de `SearchBackendInterface`.
5. **Le scoring reste post-requête.** Filtrage SQL, ranking PHP sur `maxResults * 2`.
6. **Rôle minimum configurable** (`minimum_role`, `ROLE_ANONYMOUS` ouvre à tous).
7. **Front, routing, build d'assets : hors périmètre de cette tâche.**

## Limites connues, assumées

- `FETCH_FACTOR = 2` : un terme qui matche mille lignes n'en classe que les deux cents
  premières que la base a renvoyées. C'est le plafond du principe, pas un bug.
- Les champs déclarés doivent être du texte ; le `querySearchNumber` du legacy n'est pas repris.
- `RouteSearchProvider` ne voit que `#[IsGranted]` : une page protégée par un pattern de
  firewall ou par un test dans l'action est listée.
- Collision possible si une entité s'appelle `Route` (type `route` déjà pris par le provider).
- Le titre d'une page est le nom de route humanisé, faute de traduction des routes. Ce que
  ça donne en vrai, vu dans la démo : « Wexample design system generic content media ».
  C'est lisible et c'est laid ; le câbler sur symfony-translations est la suite évidente.
- `assets/data/entity/search_result.json` n'a pas de clé `package`, là où
  `symfony-money` porte `"package": "@wexample/symfony-money"`. Sans elle, une app
  régénère l'entité chez elle au lieu de l'importer du package npm. À remplir quand le
  front arrivera, pas avant : il n'y a pas encore de `package.json` ici.
- Le filtre des routes internes porte sur le **nom** (`_profiler_*`, `_system_*`), pas sur
  le chemin. Un chemin en `/_…` dont le nom ne commence pas par `_` passe — et c'est
  voulu : les pages `/_design_system/…` de la démo sont du contenu, pas de la plomberie.
